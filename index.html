Adaptive Plant Health Decision Support System

GitHub
Course Project

Built on STM32F103C8T6 (ARM Cortex-M3) integrating DS18B20 (temperature), BH1750 (light intensity), and YL-69 (soil moisture) sensors with real-time decision logic.

User-configurable plant profiles stored in AT24C256 EEPROM; readings and recommendations displayed on SSD1306 OLED via I2C.

Alarm subsystem via passive buzzer triggered by timer-based interrupt when sensor values fall outside profile thresholds.

Unified ADC, GPIO, I2C, EEPROM, 4×4 keypad input, and interrupt control in a single embedded system.

BADR: Budget-Aware Draft Reasoning for Bengali LLM Token Optimization

Shuaib et al. 2026

A Bengali LLM token optimisation framework combining TALE-EP, Chain of Draft, and ES-CoT techniques. Achieved 89.7% token reduction with only ~2.7% accuracy drop on Bengali math benchmarks. Identified follow-up directions including English cross-lingual comparison and Bangla token elasticity reversal.

An architecture and experimental evaluation of multi-objective RL agent trained to operate across multiple, structurally distinct environments.
